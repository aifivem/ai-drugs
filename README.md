# ai-drugs

Drug corner selling and weed plants.

Part of [AI Core](https://aifivem.com): a TypeScript FiveM framework where every script is configured in one in-game admin panel, and ESX, QBCore and Qbox scripts run unchanged.

## Install

The [AI Core txAdmin recipe](https://github.com/aifivem/aicore-server) installs it with everything it needs. By hand: put this folder in `resources/[ai]/` and add `ensure ai-drugs` to `server.cfg` after `ensure ai-core`. It needs `ai-core`. The build (`dist/`, `fxmanifest.lua`) is committed, so no build tools are needed to run it.

Settings live in the in-game admin panel (`/aiadmin`), not in config files.
